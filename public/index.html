VIDEO SEO

SEO packages for the channel

Amaana detects metadata gaps and applies grounded SEO titles, descriptions, and tags to videos that are already public. Private, unlisted, and unpublished videos remain untouched. Existing links and disclosures are preserved. Channel keywords follow topics from analyzed public videos.

Tags can help correct spelling, but they are not evidence of Google ranking lift. Public videos with the fewest known views are listed first. The read-only YouTube Analytics autopilot refreshes Google-domain referral views and YouTube Search views for public videos in low-view-first batches. Reconnect YouTube once to grant Analytics access.

Google-domain referrals count video views attributed to an external Google source; they do not include Search Console impressions or average position. Use the CSV import below for those Google Search metrics.

Import Google Search Console performance

Add or select the @saevond YouTube platform property in Search Console. Open its Performance report, set the date range, and export the Videos table as CSV. If Google downloads a ZIP, extract and upload its Videos CSV here. Older Pages or Posts CSV exports are also accepted. The report contains Google impressions, clicks, CTR, and average position; it measures Google Search performance, not YouTube recommendations.

New YouTube properties may take up to 48 hours to show data. Search Console exports can be capped at 1,000 rows; if a low-view video is missing, filter the report by its URL and import that video's CSV for the same dates. Amaana imports CSV exports because Google's current Search Console API documentation does not expose platform-property reports.

Open Search Console · Platform property setup · CSV export instructions

Each import updates the video rows present in that file; other rows for the same dates stay saved because Search Console exports can be truncated. Use equal-length, non-overlapping date ranges to compare performance.

Amaana reads YouTube's spoken-audio language when available, but the public YouTube Data API cannot set it or report generated dubbing tracks. Use YouTube Studio → Languages to verify generated audio and Settings → Channel → Advanced settings for channel dubbing preferences.
